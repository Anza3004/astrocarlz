**Fecha**: 11 de octubre de 2026

##  Objetivo
Configurar Tailwind, fuentes y layout base para el sitio de AstroCarlZ.

##  Logros
- Tailwind CSS 4 instalado y configurado
- Paleta de colores custom (azul marino + dorado)
- Fuentes de Google: Cormorant Garamond + Inter
- Layout base con SEO y Open Graph
- Estructura de carpetas limpia (layouts/, pages/, styles/)
- Landing inicial con "AstroCarlZ" y "40+ años de experiencia"

##  Problemas resueltos
1. **Layout en carpeta incorrecta**: estaba en `pages/Layout/` → movido a `src/layouts/`
2. **Convención de nombres**: carpeta `layout` → `layouts`, archivo `layout.astro` → `Layout.astro`
3. **Tailwind no instalado**: el comando `npx astro add tailwind` no instaló las dependencias → instaladas manualmente con `npm install tailwindcss @tailwindcss/vite`
4. **CSS con link**: en Astro se usa `import` en el frontmatter, no `<link>` en el head

##  Aprendizajes
- En Astro, el CSS se importa con `import "../styles/global.css"` en el frontmatter
- Las carpetas van en minúscula (`layouts`, `pages`) y los componentes en mayúscula (`Layout.astro`)
- `@ts-ignore` se usa cuando TypeScript no reconoce los imports de archivos `.astro`
- Tailwind 4 usa `@theme` en CSS en lugar de `tailwind.config.js`
